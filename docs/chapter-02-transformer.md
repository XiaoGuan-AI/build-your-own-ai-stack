## 2.1 为什么是注意力（30 秒历史课）

Transformer 之前，处理序列靠 RNN/LSTM：逐个词往后传状态。两个致命伤：

1. **串行**：第 100 个词必须等前 99 个算完 → 没法并行，训练慢
2. **健忘**：长距离依赖（句子开头的词决定结尾的语法）经过太多步后信息衰减

**注意力机制（Attention）一招解决**：每个 token 直接「看」序列里所有其他 token，自己决定该关注谁。全程矩阵乘法，可并行，无遗忘。

> **直觉锚点**：RNN 是传纸条（一个人一个人传，前面的人说什么你只能听转述）；注意力是开圆桌会议（所有人同时发言，你自己决定听谁的）。

## 2.2 注意力直觉：一个 Query 在图书馆找书

每个 token 变成三个向量，用图书馆类比：

| 向量 | 图书馆角色 | 含义 |
|------|-----------|------|
| **Query（Q）** | 你在找什么 | 「我要找讲矩阵的书」 |
| **Key（K）** | 每本书的标签 | 「这本书标签是矩阵」 |
| **Value（V）** | 书的内容 | 这本书的实际内容 |

找书过程：
1. 你的 **Q** 和每本书的 **K** 算相似度（点积）→ 「哪本书最相关」
2. 相似度过 **softmax** 变成权重（所有书的权重和为 1）
3. 按权重**加权求和**所有书的 **V** → 你带走的「综合信息」

```
attention = softmax( Q·Kᵀ / √d ) · V
              └─ 相关性打分 ─┘   └─ 加权汇总 ─┘
```

**为什么除以 √d（d = 向量维度）？** 点积结果随维度变大而变大：d 维向量点积的方差 ≈ d。不缩放的话，分数动辄几十上百，softmax 会**饱和**——最大的分数吃掉全部概率，梯度几乎为 0，模型学不动。除以 √d 把分数拉回 O(1) 量级。

## 2.3 多头注意力：一群专家分头找书

一个头只能学一种「关注模式」，多头 = 多个并行的注意力，每个头学不同的关系：

- 一个头关注**语法角色**（主语找谓语）
- 一个头关注**指代**（「它」找「狗」）
- 一个头关注**主题**（「医疗」相关的词互相抱团）

实现：把 d_model 维拆成 n_heads 份，每份 d_model/n_heads 维独立算注意力，最后**拼回去**再过一层输出投影。参数总量没变，但模型有了「分头看问题」的能力。

---

## 2.4 因果掩码：生成时不能偷看未来

大模型生成是**逐个 token** 的：预测第 t 个词时，只能看 1..t-1 的词。如果注意力能看到未来，训练时模型会直接「抄答案」——预测的词就是下一格的词，学不到任何东西。

解法：**上三角掩码**。注意力分数矩阵（T×T）中，`i < j`（未来位置）的部分填 `-inf`，softmax 后变成 0：

```
       看 的 位 置
      [1 0 0 0]      ← 第 1 个 token 只能看自己
      [1 1 0 0]      ← 第 2 个 token 能看 1、2
      [1 1 1 0]
      [1 1 1 1]      ← 最后一个 token 能看全部（也是训练时的真实情况）
```

```python
mask = torch.tril(torch.ones(T, T)).bool()   # 下三角 = 只留「过去和现在」
att = att.masked_fill(~mask, float("-inf"))  # 未来位置 = -inf → softmax 后为 0
```

> 训练时用「整个序列一次性前向 + 掩码」，就等价于「逐 token 生成」——**这是 Transformer 能并行训练的关键**。

## 2.5 位置编码：注意力天生没有顺序感

注意力是「全体互看」，如果输入只有 token 向量，模型分不清「猫咬狗」和「狗咬猫」。所以给每个位置加一个**位置信号**。

GPT 用**可学习的**位置编码（训练时顺便学）；教学版用 **sinusoidal**（正弦波，不需要训练）：

```python
pos_enc[pos, 2i]   = sin(pos / 10000^(2i/d))
pos_enc[pos, 2i+1] = cos(pos / 10000^(2i/d))
```

不同频率的正弦波叠加，让每个位置有独一无二的「指纹」，且相邻位置指纹相似（位置 3 和 4 的向量接近，位置 3 和 500 差很远）——**模型能从向量相似度读出距离**。

---

## 2.6 残差连接 + LayerNorm：深层的两个安全带

堆 12 层、24 层 Transformer 时，梯度要穿越所有层，容易爆炸/消失。两个标准件解决：

**残差连接**：`x = x + Attention(LayerNorm(x))`——梯度有一条「高速公路」直达底层，最坏情况退化成一个恒等映射（啥都不学，但也不崩）。

**LayerNorm**：对每个 token 自己的 d 维向量做归一化（均值 0 方差 1），防止数值爆炸，让每层输入分布稳定。注意它和 BatchNorm 不同：**不跨样本**，所以单条样本也能算。

---

## 2.7 前馈网络（FFN）：token 的「独立思考时间」

注意力是 token **之间**的信息交换（混合），但每个 token 还需要**自己的**非线性变换（思考）。FFN 就是每个位置独立过一遍两层 MLP：

```
FFN(x) = GELU(x·W₁ + b₁)·W₂ + b₂    （先把维度放大 4 倍，再压回来）
```

「注意力开会 → FFN 各自消化」交替进行，就是 Transformer block 的完整节奏。

## 2.8 完整前向（一张图）

```
token ids [1, 42, 77, 3]
   │
   ▼
token embedding ────┐
pos 编码 ───────────┴→ x（每个 token 变成 d 维向量）
   │
   ▼
┌─ Block ×N ───────────────────────┐
│  x = x + Attn(LayerNorm(x))      │   ← 注意力：token 间交流
│  x = x + FFN(LayerNorm(x))       │   ← FFN：token 内思考
└──────────────────────────────────┘
   │
   ▼
LayerNorm → Linear（词表大小）→ logits
   │
   ▼
softmax → 下一个 token 的概率分布 → 采样
```
