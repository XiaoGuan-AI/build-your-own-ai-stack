## 0.2 张量直觉（10 分钟）

**张量（Tensor）= 带形状的多维数组。** 就这么简单。

| 名字 | 形状 | 例子 |
|------|------|------|
| 标量 | `()` | 3.14 |
| 向量 | `(n,)` | `[1, 2, 3]` |
| 矩阵 | `(m, n)` | 表格，m 行 n 列 |
| 3 维张量 | `(b, m, n)` | b 张矩阵叠起来 |

**LLM 里你只见到四种操作：**

1. **查表**（embedding）：`token_id -> 向量`。一个 50257 行的表，按编号取一行。
   ```python
   词汇表 = torch.randn(50257, 768)   # 每个 token 一个 768 维向量
   某个token = 词汇表[42]             # 查表，形状 (768,)
   ```
2. **矩阵乘法**（线性层）：`x @ W + b`。Transformer 里所有「变换」都是它。
   ```python
   x = torch.randn(4, 768)        # 4 个 token，每个 768 维
   W = torch.randn(768, 768)      # 权重矩阵
   out = x @ W                    # 形状 (4, 768) —— 每个 token 被「旋转+缩放」
   ```
3. **逐元素运算**：`+ - * /`、`exp`、`softmax` 等，把每个数单独处理。
4. **归一化**（softmax / layer-norm）：让一堆数变成概率分布或稳定尺度。

> **关键直觉**：训练模型 = 不断调整 W 这些矩阵里的数字，让输出的结果越来越符合期望。**调整的依据就是梯度。**

## 0.3 梯度直觉（15 分钟）

**导数 = 斜率 = 「输出会随输入变化多少」。** 例：`y = 3x`，x 从 2 变成 2.01，y 从 6 变成 6.03——斜率是 3。

**多维怎么办？** 一个模型有几百万个参数 w₁, w₂, …, wₙ，损失 L 对每个参数都有一个「偏导数」∂L/∂wᵢ，意思是：「如果只把 wᵢ 动一点点，L 会变多少」。把所有偏导数排成一列，就是**梯度** ∇L。

**反向传播 = 沿着算式链往回分「锅」。** 大白话：

> 你预测错了，损失 L 很大。这口「锅」要分给谁？
> 前向传播时，L 是经过一系列运算算出来的：`L ← y_pred ← (w·x+b) ← w, x, b`。
> 反向传播就是**倒着走这条链**，用链式法则（微积分的「复合函数求导」）算出每个中间量、每个参数各自该承担多少责任（梯度）。
> 然后梯度下降走一步：`w = w - 学习率 × ∂L/∂w`。重复几百万次，模型就学会了。

**不用背公式，跑一遍代码你就懂。** 第 0 章热身代码 `code/ch00/micrograd.py` 用 60 行实现了一个微型自动微分引擎（Karpathy 的 micrograd 简化版）。**强烈建议现在就跑：**

```bash
python code/ch00/micrograd.py
```

你会看到一行行 `w = ... loss = ...`——一个参数从 0 开始，自己学会了 y ≈ 3x+2。**第 3 章你训练大语言模型，用的就是这个机制，只是规模大了几百万倍。**

读代码时盯着三件事：
1. `Value` 是怎么记住「我是谁算出来的」（`_prev` 和 `_op`）
2. 加法/乘法的 `_backward` 是怎么定义「锅怎么分」的
3. `backward()` 的拓扑排序为什么要「从输出往前」

## 0.4 检验点（Checkpoint）

**判断题（答案在文末）：**

1. 「PyTorch 的 `tensor.backward()` 能自动求梯度，是因为 PyTorch 在你做前向运算时偷偷记录了算式图。」 —— 对 / 错
2. 「LLM 的推理（前向传播）本质上就是大量矩阵乘法。」 —— 对 / 错
3. 「梯度下降时，参数要往梯度方向（∇L）移动，因为那是最快增大的方向。」 —— 对 / 错

**动手实验（选做）：**

- 改 `micrograd.py` 的 `lr`（学习率）从 0.01 改成 1.0，看会发生什么？改成 0.0001 呢？你观察到的现象叫什么名字（提示：发散 / 收敛慢）？
- 在 `Value` 上自己加一个 `__truediv__`（除法）：`a / b = a * (b ** -1)`，利用已有的乘法实现。

---

<details>
<summary>答案（先自己做完再看）</summary>

1. **对。** 这就是自动微分（autograd）的原理：前向运算构建计算图，反向按图传播梯度。
2. **对。** 注意力、线性层、MLP 全部是矩阵乘法 + 逐元素运算。这也是 GPU 擅长 AI 的原因——GPU 就是为大规模并行矩阵乘法设计的。
3. **错。** 梯度指向「函数增大最快」的方向；我们要**减小**损失，所以往**负梯度**方向走：`w = w - lr * ∂L/∂w`。

学习率实验：lr 太大（1.0）→ 震荡/发散（loss 变成天文数字）；lr 太小（0.0001）→ 收敛极慢。这就是「学习率是超参数里最重要之一」的原因。

</details>
